# Тульская фармацевтическая фабрика — редизайн сайта

Статический сайт: главная, каталог из 125 препаратов, карточки препаратов и политика конфиденциальности.

## Структура

- `index.html` — главная (вёрстка вручную)
- `catalog.html`, `products/*.html`, `policy.html` — генерируются, руками не правятся
- `data/catalog.json` — категории и препараты: название, форма выпуска, фото, разделы инструкции, ссылка на PDF
- `data/policy.html` — текст политики конфиденциальности
- `css/style.css` — общие стили всех страниц
- `img/products/` — фото упаковок (WebP)

PDF-инструкции и разрешительные документы лежат не в репозитории, а в релизе
[`documents`](https://github.com/antonseliverstov/tulapharm-redesign/releases/tag/documents): там 124 файла, около 490 МБ.

## Пересборка страниц

После правок в `data/` или в шаблонах:

```bash
node scripts/build.mjs
```

Скрипт пересоздаёт `catalog.html`, `policy.html` и папку `products/`.
